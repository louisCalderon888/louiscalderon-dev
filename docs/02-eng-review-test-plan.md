## Edge Cases
- JSON del feed ausente (primera carga o script caído) → widget muestra bloque estático, NO pantalla vacía — en widget
- JSON malformado → fallback estático sin romper la página — en widget
- JSON estancado (>48h) → fecha de última actualización visible en rojo/énfasis, no dato silencioso — en widget
- Firma sin regla publicada → fila "sin regla publicada — confirmado con support, fecha" — en /ninjatrader/matriz
- Consentimiento del cliente NO otorgado → bloque de caso sustituido por log de operativa propia — en /ninjatrader
- Scan de copy: 0 ocurrencias de "garantizado/asegurado/ganarás/rendimiento garantizado" en todas las páginas — en todas
